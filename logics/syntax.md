# 1차 논리의 구문론(Syntax of First Order Logic)

**1차 논리의 구문론** 을 하기에 앞서 구문론에 대해 간략히 소개한다.

구문론은 언어학의 개념으로 어떠한 언어가 어떠한 기호로 구성되고, 기호들이 어떠한 규칙으로 결합되어 말을 이루는지를 탐구하는 분야이다.

즉 1차 논리의 구문론을 공부한다는 것은 논리학을 언어학의 관점으로 접근한다는 의미가 된다. 의미론도 마찬가지이다. 의미론 또한 본래 언어학에 뿌리를 두기 때문에 논리학을 언어학의 관점에서 접근하는 방식이다.

그렇다면 1차 논리에서 언어는 무엇인지 알아보도록 하자.

## 1차 논리 언어

**1차 논리 언어**는 주어진 논리 체계를 표현하기 위한 언어이다. 무엇이 1차 논리 언어인지 안다는 것은 1차 논리 언어가 어떤 기호를 사용하며 그 기호들을 어떻게 조합하여 말을 만드는지를 안다는 것이다. 기호부터 시작하자.

> ### 1차 논리 언어의 기호
>
> * 논리 기호 (logical symbols)
>
>   * 논리적 연결사 (logical connectives)
>
>       $\neg, \lor, \wedge, \rightarrow, \forall, \exists$
>
>   * 논리적 모순 기호 (falsity)
>       
>       $\bot$
>
>   * 등호 (identity predicate)
>
>       $=$
>
>   * 변항 (variables)
>
>       $v_0,v_1,...$
>
> * 비논리 기호 (non logical symbols)
>
>   * $n$항 술어 기호 (n-place predicate symbols)
>
>       $P_0^n,P_1^n,...$
>
>   * 상수 기호 (constant symbols)
>
>       $c_0,c_1,...$
>
>   * $n$항 함수 기호 (n-place functional symbol)
>
>       $f_0^n,f_1^n,...$
>
> * 문장 부호 (punctuation)
> 
>   $(,),comma$

술어 기호, 함수 기호의 위첨자 $n$은 몇 개의 항이 필요한지 알려주는 느낌이다.
